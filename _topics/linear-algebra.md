# Linear Algebra

Linear algebra studies vectors, matrices, and linear transformations, forming the backbone of much of applied mathematics, statistics, and machine learning.

## Topics

- Vectors and vector spaces
- Matrix operations
- Systems of linear equations
- Eigenvalues and eigenvectors
- Determinants
- Linear transformations

## Popular concepts

- Matrix multiplication
- Eigenvectors
- Rank and null space
